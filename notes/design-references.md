# 2부. 취향 특성 (도출된 원칙)

## 원칙 1 — 형태: "완전 pill도, 많이 둥근 것도 아닌 중간"

가장 여러 번, 가장 구체적으로 교정한 축입니다.

- 카드·박스 모서리는 **작게**. 많이 둥근 걸 **싫어함** → 20px에서 **10px로 내림**.
- 버튼·태그·내비는 **완전 pill(999px) 아님** → **부드러운 라운드 사각형**.
  - `.pill` **13px** / 내비 컨테이너 15px / 내비 링크 10px / 뱃지 8px
- **원형은 아이콘 버튼(테마 토글)에만.**
- **여백은 넉넉하게** — 텍스트와 테두리 사이 `padding: 9px 18px`.

> 요약: **각지지도 둥글지도 않은 중간값**을 좋아하고, 그 안의 여백은 후하게.

## 원칙 2 — 색: 최소한으로, 의미에만

색을 예쁘게 쓰는 게 아니라 **의미로** 씁니다. 핵심은 **색 가짓수를 늘리지 않는 것**이지,
한 상태를 한 가지 색으로만 표현하라는 뜻이 **아닙니다** (2026-08-23 본인 확인).
색을 새로 만들지 않고 표현하는 채널 — 명도·불투명도·형태 — 은 겹쳐 써도 됩니다.

| 색 | 역할 | 규칙 |
|---|---|---|
| 네이비 `#16233B` | 브랜드 · 선택 상태 (활성 국가, 활성 필터) | |
| 테라코타 `#B65C36` | 포인트 (도시 마커, 팁) | **네이비와 역할 절대 혼용 금지** (원문 표현) |
| 세이지그린 `#5B7553` | 방문 완료 | 방문을 나르는 **색**은 이것 하나. 색이 아닌 채널로 방문을 나르는 것은 별개 |
| `--c1`~`--c6` | 카테고리 6종 | 브랜드색과 **별도** 체계 |

배경은 웜그레이 `#EDEAE1`(라이트) / `#15181A`(다크). **단색이 아니라** 은은한 radial 블롭이 깔림.

**적용 예** (2026-08-23): 세계지도에서 나라의 방문 기록을 **네이비 불투명도 50% → 100%**로 표현.
새 색을 만들지 않았으므로 원칙에 어긋나지 않고, 세이지그린의 방문 완료 역할과도 충돌하지 않는다.

## 원칙 3 — 타이포: 역할별로 3분할

| 역할 | 폰트 계열 |

## 원칙 4 — 절제: 무게감을 싫어함

- 그림자·글로우는 **아주 은은하게만**. 네온·블러 글로우 **금지**.
- 얇은 테두리 위주. 두꺼운 채움 지양.
- 차분하고 여백이 넉넉한 분위기.

## 원칙 5 — "AI가 만든 것 같은 느낌"을 강하게 거부

원본 스펙에 **명시적으로 피할 것**으로 열거된 항목들:

- 그림자 + 두꺼운 채움 + **전부 대문자 트래킹**을 남발하는 **"AI 생성 SaaS" 느낌** pill 버튼
- **크림 + 테라코타의 흔한 AI 배색**
- 툴 같은 UI 크롬

## 원칙 6 — 진짜 데이터, 진짜 사진

- 국가 모양은 **일러스트 금지, 실제 국경선 데이터**. 내부 행정구역 경계까지.
- 카드 이미지는 **실제 랜드마크 사진**(Wikipedia/Commons). 플레이스홀더·일러스트 아님.
- 명소 설명의 건립연도·건축가·유네스코 지정연도 등은 **웹 검색으로 검증**, 추측 금지.
- 사진이 **문장(紋章)·깃발·노선도**로 잘못 나오면 실제 사진으로 교체 (옥스퍼드→래드클리프 카메라, 스카이 섬→올드 맨 오브 스토어, 트란스파가라샨→실제 도로 사진).

## 원칙 7 — "지저분한 것"을 못 참음 (정돈하거나, 없앤다)

**정돈 방법을 요구하거나, 아예 제거를 제안합니다** (2026-08-23 본인 확인).
어느 쪽인지는 그때그때 다르므로, 지저분하다는 말이 나오면 **정돈안과 제거안을 함께 올린다.**

정돈으로 푼 것:

- 도시 라벨이 겹침 → **그리디 라벨 배치**(우/좌/하/상 후보 중 안 겹치는 위치) + 흰색 후광
- 나라 콜아웃 pill이 겹침 → **자동 디컬리전**(측정 후 아래로 밀기, 리더선 재연결) — *2026-08-23에 제거됨*
- 폰에서 나라 이름이 **"지저분해"** → **줌/팬 도입 + 유럽 포커스 기본 뷰 + 폰트 축소**(0.68rem / 모바일 0.6rem) + 화면 밖 라벨 숨김 — *줌/팬은 유지, 폰트 축소·라벨 숨김은 라벨과 함께 사라짐*

제거로 푼 것:

- 나라 이름 32개가 상시 떠 있는 것 → **말풍선·리더선·디컬리전을 통째로 걷어내고 호버 라벨 하나로** (2026-08-23)
- 나라 위의 앵커 점 → **삭제.** 폴리곤이 아예 없는 몰타·카나리아 제도만 남김 (2026-08-23)

# 3부. 시간순 피드백 원문 기록

## 박스·카드 (2026-07-12)
- **모서리**: 박스/카드는 많이 둥근 걸 싫어함 → 작은 라운드(10px). 버튼/pill은 이전에 좋아한 라운드 유지.
- **좌측 색깔 포인트 금지**: 박스 왼쪽 보더 강조(accent stripe) 싫어함 → 상태 표시는 전체 보더 색으로.
- **사진 카드**(참고: https://21st.dev/@ravikatiyar/components/card-21): 도시 카드는 랜드마크 사진을 꽉 채우고 이름을 오버레이한 '데스티네이션 카드'. 명소 카드는 커버 사진 + 카테고리 태그. **"explore now" 문구 쓰지 않음.**
- **소감 박스**: 원형 프로필 없음, 그 자리에 방문 체크박스. 아이디 줄은 `@아이디` → 방문일 입력 시 날짜 범위(M월 D일 ~ M월 D일) 표시. 방문일은 시작·종료 2개.
- 사진 출처: Wikipedia/Wikimedia Commons (`build/fetch-images.mjs`, Special:FilePath?width=640).

## 버튼 형태 (첨부 이미지 IMG_6963 — 'Air Max 90 / + Add' 카드, 2026-07-11)
**마음에 든 요소** (직접 언급): 요소 테두리의 굴곡(완전 pill이 아닌 부드러운 라운드 사각형), 텍스트와 테두리 사이의 넉넉한 여백.

**반영 결정**: 버튼·태그·내비게이션을 완전 pill(`border-radius: 999px`)에서 **부드러운 라운드 사각형**으로 전환.
- `.pill`: `border-radius: 13px`, `padding: 9px 18px`
- `.nav-links`: 컨테이너 `15px`, 링크 `10px` / `padding: 9px 18px`
- `.route-badge`(확정·선택 태그): `border-radius: 8px`
- 카드(`.panel` 등)는 16~20px 유지 → 이후 2026-07-12 피드백으로 **10px로 축소**
- 원형 아이콘 버튼(테마 토글)은 원형 유지

## mycalmsite.com (2026-07-11)
**링크**: https://mycalmsite.com/
**마음에 든 요소** (직접 언급): 배경 색의 그라디언트, 요소의 색감 및 형태

라이트/다크 모드로 실제 사이트를 열어 스크린샷·computed style 확인 결과:
- **배경**: 완전 단색이 아니라 큰 원형 `radial-gradient(circle, color 0%, transparent 72%)` 블롭 3~4개를 절대 위치로 겹쳐 은은하게 번지는 느낌. 라이트는 연보라/연핑크/하늘색/민트, 다크는 같은 블롭이 짙은 배경 위 보라/자홍 광원처럼 보임.
- **버튼/탭 형태**: 완전 pill (`border-radius: 50px`).
- **그림자/글로우**: 주요 CTA에만 아주 은은한 glow (`0 0 32px rgba(255,255,255,0.08)` 수준, 하드한 네온 아님).
- **폰트**: Poppins 계열(지오메트릭 산세리프).
- **분위기**: 차분하고 여백이 넉넉. 장식 요소(중앙의 유리질 구체)는 프로젝트 성격과 안 맞아 미채택.

**최종 반영**: 기존 웜그레이/네이비/테라코타 팔레트는 유지하고, mycalmsite에서는 ① 블롭 배경 기법, ② pill 형태, ③ 절제된 glow만 가져와 **기존 팔레트 색으로 다시 그림**. 라벤더/핑크 색 자체는 미채택.
